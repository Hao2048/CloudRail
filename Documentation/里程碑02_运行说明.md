# 云上列车可玩旅程

场景：`Assets/Scenes/CloudRail_Journey.unity`

第二个里程碑将第一版观景场景扩展为三站可玩的旅程。原有 `CloudRail_Milestone01.unity` 继续保留。

## 操作

| 操作 | 效果 |
| --- | --- |
| WASD | 按镜头方向行走 |
| 鼠标右键拖动 | 转动步行镜头 |
| 鼠标滚轮 | 拉近或拉远步行镜头 |
| E | 与附近装置交互、上车，或在列车停稳后下车 |
| F | 乘车停站时打开目的地选择 |
| C | 乘车时切换三个观景镜头 |
| Esc | 关闭当前菜单，或打开和关闭暂停菜单 |

点击开始面板的“启程”后即可游玩。目的地菜单、暂停设置、重新开始确认和结局面板均支持鼠标操作。

## 三站主线

1. 云起站有三枚星光。沿月台和站旁坡道探索，集齐后在月台的发光装置按 E，开放花园航线。
2. 靠近停在月台的小火车按 E 上车，按 F 选择花园岛。列车不会在玩家下车后自行离站。
3. 花园岛有六枚星光，找到任意三枚，使累计数量达到六枚，即可激活下一段航线。
4. 上车前往星钟岛，沿月台坡道进入岛屿，在钟塔旁的装置按 E。等待钟塔苏醒后，可以继续探索。
5. 通关后仍可往返相邻车站，补齐九枚星光。解锁与钟塔激活均不消耗星光。

月台装置和星光都有明确的世界内造型；屏幕上方显示当前目标与累计收集数量，下方显示当前可用操作。

## 安全与存档

- 列车行驶和进站期间不能下车，也不能再次发车。
- 每次到站停稳后更新安全车站。乘车中退出，重新打开后在出发站月台恢复为步行状态。
- 收集、解锁、到站、完成结局和修改设置后自动保存。
- 角色意外跌落后返回当前车站的安全点，保留收集进度。
- 已收集的星光不会再次出现；已开放航线和已完成结局保留。
- 存档通过临时文件替换，并保留上一份有效备份。无法读取两份存档时，显示恢复说明，阻止静默覆盖原文件。
- 暂停菜单可调整音效音量和观察灵敏度；重新开始需要确认，并保留这些偏好。

正式进度文件位于 Unity 的 `Application.persistentDataPath`，文件名为 `cloudrail_journey_v1.json`。流程测试使用独立的 verification 文件，不写入玩家进度。

## 项目组织

- `Assets/CloudRail/Scripts/JourneyGame.cs`：进度、交互、路线解锁、收集与结局。
- `Assets/CloudRail/Scripts/JourneyTrain.cs`：三站之间的手动发车、制动与到站。
- `Assets/CloudRail/Scripts/JourneyPlayer.cs` 和 `JourneyCamera.cs`：角色移动、碰撞与镜头。
- `Assets/CloudRail/Scripts/JourneyHUD.cs`：中文提示和菜单。
- `Assets/CloudRail/Scripts/JourneySave.cs`：存档与恢复。
- `Assets/CloudRail/Editor/CloudRailJourneyBuilder.cs`：三站场景、碰撞、角色、星光与界面的生成。
- `AgentScripts/VerifyJourney.cs`：通过虚拟键盘驱动正常移动逻辑的流程验证脚本，仅用于独立测试存档。

编辑器菜单 `Cloud Rail > Build Playable Journey` 可从第一版场景重新生成三站场景。生成的几何资源单独放在 `Generated/Gameplay`，避免改变第一里程碑的网格。重建会替换生成场景内的手动修改，需要保留时应先另存。

## 声音和字体

本阶段加入原创合成的收集、解锁和到站短提示音。完整背景配乐与进一步的环境混音留待后续美术和声音打磨阶段。

中文界面使用 Noto Sans CJK SC，来源为 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk)。项目中保留原字体与 `Assets/CloudRail/Fonts/OFL.txt` 授权文件。

## 本次验证

通过独立测试存档完成 65 项流程检查，包含正常键盘移动、主线收集、重复收集拦截、两段解锁、旅途中禁止下车、暂停、三站到达、钟塔结局、返程下车、九枚全收集与存档备份恢复。

另外验证了输入系统指针点击暂停菜单、跌落复位，以及实际停止和重新进入 Play 模式后的进度与设置恢复。验证结果保存在本目录的流程验证、鼠标验证和重新载入验证 JSON 文件中。
