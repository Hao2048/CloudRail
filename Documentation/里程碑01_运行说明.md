# 云上列车第一里程碑

场景：`Assets/Scenes/CloudRail_Milestone01.unity`

Unity 版本：6000.6.0f1，沿用项目 URP，并保存独立的 CloudRail 渲染管线配置。

## 查看方式

打开场景，点击 Play。列车会自动绕岛行驶，在车站减速停留约 2.8 秒，然后重新加速出发。一圈轨道长约 136 米，巡航速度为 4.2 米每秒。

点击 Game 画面后使用以下操作：

| 操作 | 效果 |
| --- | --- |
| 1 | 浮空岛全景 |
| 2 | 车站近景 |
| 3 | 列车跟随视角 |
| C | 循环切换三种视角 |
| 右键拖动 | 在全景视角中旋转观察 |
| 鼠标滚轮 | 在全景视角中拉近或拉远 |
| 空格 | 开关全景自动环绕 |
| Shift 加空格 | Unity 编辑器中切换当前面板最大化 |

## 本次完成内容

- 低多边形主浮空岛、连续草地边缘、岩壁切面与悬垂植物。
- 蓝顶车站、时钟塔、旋转天体环、月台、雨棚、长椅和灯柱。
- 环形拱桥高架铁路、轨枕、双轨与拱门金属饰边。
- 蒸汽机车与一节观景车厢，独立保存为可复用 Prefab。
- 按轨道距离运行、车厢独立跟随、车轮与连杆运动、世界空间蒸汽粒子。
- 自动进站减速、停站和重新发车。
- 漂浮云层、远景小岛、瀑布流动、花园喷泉和三种观察镜头。
- 保存生成的网格、材质、体积后处理配置和完整场景；重新打开场景即可运行。

## 编辑与重建

主要运行脚本位于 `Assets/CloudRail/Scripts`。在 Inspector 中可调整 `CloudTrain` 的速度、加减速与停站时间，以及 `CloudRailCamera` 的初始观察角度。

编辑器菜单 `Cloud Rail > Build Milestone One` 根据固定随机种子重新生成里程碑场景。重建会重新创建这个生成场景，并更新本里程碑的生成资源；需要保留手动修改时，请先另存场景与相关资源。当前场景有未保存修改或处于 Play 模式时，重建会拒绝执行。

场景中的静态部件按材质合并，以控制绘制数量；合并后的几何以资产保存，原始构建逻辑在 `Assets/CloudRail/Editor/CloudRailBuilder.cs` 中。
