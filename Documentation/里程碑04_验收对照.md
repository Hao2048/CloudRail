# 内容交付批次与 V0.1 设计对照

设计文档中只有三个大阶段。本项目将声音单列为实现批次 03，本批次 04 完成第三阶段剩余的内容与交付工作，未扩展战斗、经营、联网或自由铺轨等首版边界外系统。

| 设计要求 | 本批实现 / 验证依据 |
|---|---|
| 三岛统一风格与不同地标 | 云起车站、花园花廊喷泉、星钟塔与星座灯；Release 场景和展示片 |
| 云层、瀑布与环境动画 | 漂移远景岛、花瓣、流水材质、瀑布雾气 |
| 解锁产生世界变化 | 两组信号翼打开、120 盏轨旁导光灯、六秒引导光波、文字状态 |
| 六枚完成，九枚奖励 | 主线六枚终点不变；九枚点亮云起站纪念灯，按唯一星光 ID 恢复 |
| 收集先记进度再表现 | 唯一 ID 计数立即保存；脱离拾取物的视觉播放 0.4 秒收缩上浮 |
| 原创音乐与空间声音 | 原创 96 秒循环已完成；新增原创瀑布空间声，音量随距离衰减 |
| 暂停帮助与减少晃动 | H / 菜单随身手册，稳定镜头开关，偏好自动保存 |
| 性能备用档 | 完整云层 60 帧上限，轻量云层 / 粒子 30 帧上限 |
| 中途退出恢复提示 | 保存行驶标记，到站清除；恢复至出发站并提示未完成旅程 |
| 连续三轮核心流程 | `里程碑04_流程验证_1/2/3.json`，合成键盘驱动正常玩家移动和碰撞 |
| 本机试玩构建 | `Builds/macOS/Cloudline.app`，构建结果见 `里程碑04_构建验证.json` |
| 构建版性能验证 | 在独立诊断存档中跑两段实际列车行驶、三站场景与钟塔；记录芯片、内存、系统和实际渲染分辨率 |
| 展示视频 | Unity 独立构建实机逐帧采集，配项目原创配乐；非概念图或外部素材剪辑 |
| 真人首轮体验 | 尚未完成。需三名未参与制作的体验者验证独立通关、卡点和时长，不能用自动验证替代 |
