# 云上列车：视觉方向与平台约束

用户已明确：本项目只做电脑端。后续不设计手机触屏操作、不制作移动端适配或 Android / iOS 构建。

用户进一步明确：核心是画面视觉和观景，观看优先于游玩。制作优先级为建模轮廓、二次元色彩、清澈光照、列车与环境运动、构图和沿途景观，避免把主要工作转移到任务面板与玩法闭环。

本轮视觉样板：`Assets/Scenes/CloudRail_Visual.unity`。沿用三座岛屿，加入卡通分层着色、明亮的蓝绿与樱花配色、圆润倒角和弧面屋顶，以及列车前方的分段铁路展开效果。默认自动观景，C 切换镜头，右键环绕，滚轮调距，空格暂停，Tab 切回探索。

画面原则：暖色受光面与蓝紫阴影区分形体；薄雾只用于远景；车身、建筑与云层保持清晰色块；桥体先落稳，再连接枕木与钢轨，连续段落以错峰动作形成流动波浪。正式探索时铁路恢复完整。

界面体验的未完成草稿已移到 `AgentScripts/DeferredDesktop`，不会参与本轮场景运行。

本轮按用户要求，以必要的编译和实机画面查看完成交付，不重复运行既有整套流程、性能和存档测试。之前的 macOS 试玩包对应上一批次；最新视觉修改以本轮 Unity 场景为准。
