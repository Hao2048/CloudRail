# 云上列车 · 内容与交付里程碑

这是设计文档“阶段三：完善内容与交付”的实现批次。上一批次先完成声音，本批补充环境细节、进度反馈、辅助设置，并交付本机试玩构建与实机展示片。

## 打开与游玩

- Unity 项目根目录：`项目目录`，Unity 6000.6.0f1。
- 本轮场景：`Assets/Scenes/CloudRail_Release.unity`。在 Unity 中运行并点击“启程”。先前的 `CloudRail_Journey.unity` 和第一里程碑场景继续保留。
- 本机试玩：`Builds/macOS/Cloudline.app`。构建和运行验证结果另见 JSON 报告。
- WASD 行走，右键拖动观察，滚轮缩放；E 操作装置或上下车，F 选择相邻站点，C 切换三种乘车镜头，Esc 暂停，H 打开或关闭随身手册。
- 暂停菜单可以调整音乐、音效、观察灵敏度，开关稳定镜头与轻量云层。轻量模式减少云层和环境粒子，并将构建版本帧率上限设为 30；默认模式上限为 60。

## 主线和可选目标

云起站沿步道找齐三枚星光，回月台激活航线；上车前往花园岛，再累计到六枚并激活第二条航线；抵达星钟岛，沿步道到钟塔按 E 点亮信标。解锁不消耗星光。

完成后可以继续往返，寻找花园支路的三枚可选星光。九枚齐集后，云起站月台的九星纪念灯点亮，恢复存档后仍保持此状态。

## 新增表现

- 云起站花坛，花园岛花廊与悬垂花簇、花圃、喷泉水弧，星钟岛朝向月台的新钟面、刻度、栏柱和发光星座。
- 远景浮岛、缓慢漂移、花瓣飘落和瀑布底部雾气。
- 航线装置有文字与打开的信号翼，解锁后引导光沿下一段铁路短暂流动，之后保持点亮。
- 星光的状态先保存，再播放约 0.4 秒的独立缩小上浮视觉；视觉不会重复增加收集数。
- 钟塔演出期间星座和灯光渐亮，结束仍可探索。
- 原创瀑布声具备空间衰减，并随音效设置和暂停状态变化。生成代码 `AgentScripts/compose_waterfall.py` 与 WAV 源音频一并保留。

## 存档与设置

沿用正式存档 `cloudrail_journey_v1.json`，不会清除现有旅程。收集、解锁、到站、通关和设置变更自动保存，并保留有效备份。旧存档兼容新增的稳定镜头等设置。

行驶中退出会恢复到出发站安全月台，并提示上次旅程尚未完成。重新开始需在暂停菜单二次确认，保留声音、灵敏度与辅助设置。

测试和录像使用带 `verification` 的独立存档，与玩家正式进度分开。
